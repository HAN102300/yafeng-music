# 🎵 雅枫音乐 v0.1.3

> **⬇️ 直接下载下方 `YaFengMusic_0.1.3_x64-setup.exe` 安装**（36.7 MB，含完整离线能力）。
> 已安装 v0.1.0–v0.1.2 的用户：启动应用约 12 秒后会自动提示更新，点击「立即更新」即可。

## ✨ 本次更新了什么

### 🔐 扫码登录彻底修复（重大）
- **之前**：扫码确认时被网易风控拒绝，报 8821「请切换其他登录方式或升级新版本再试」
- **现在**：扫码后直接登录成功，无需再手动粘贴 Cookie
- 技术细节：对齐 YesPlayMusic 后端机制——明文 `/api/` 通道 + `type:3` 匿名设备通道，
  并新增**匿名设备身份**注册（设备指纹 Cookie + `MUSIC_A` 令牌），根治风控

### ⚙️ 新增「设置」页
导航栏齿轮图标进入，五大分组：
- **播放**：默认音质（5 档）/ 默认倍速（0.5x–2.0x）
- **桌面端**：**关闭按钮行为可选**——最小化到托盘（音乐继续）或直接退出
- **数据**：清除搜索历史 / 播放历史
- **关于**：版本信息、开源仓库、技术栈

### 🖥️ 桌面体验
- **启动不再黑屏**：加载完成才显示窗口（主题底色打底，无闪白/闪黑）
- **Navbar 窄窗口不再挤压**：emoji 图标与文字自适应收缩

## 🐛 修复
- 点 ✕ 关闭行为设置不生效（JSON 解析问题，现支持「最小化到托盘 / 直接退出」真实切换）
- 更新弹窗流程重做：**发现新版先询问，用户确认才下载**；下载完成再询问是否重启安装；
  支持「跳过此版本」——不再强制下载打扰
- 启动崩溃不再无声秒退（崩溃日志写入 startup.log，run-debug 输出落盘）
