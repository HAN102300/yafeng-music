# 🎵 雅枫音乐 v0.1.4

> **⬇️ 直接下载下方 `YaFengMusic_0.1.4_x64-setup.exe` 安装**（约 37 MB，含完整离线能力）。
> 已安装 v0.1.0–v0.1.3 的用户：启动应用约 12 秒后会自动提示更新，点击「立即更新」即可；
> 或在 **设置 → 关于 → 检查更新** 手动检查。

## ✨ 本次更新了什么

### 🔄 设置页新增【检查更新】按钮
- 位置：**设置 → 关于** 区块底部
- 完整状态流转：检查中（旋转动画）→ 最新 / 发现新版 / 失败，自动提示
- 发现新版可直接下载（spring 进度条动画）→ 下载完成后「重启并安装」
- 手动检查不受「跳过此版本」偏好影响——你想看结果就一定有结果

### 📻 私人 FM 修复（重大）
- **之前**：点开提示「需要登录」，已登录也一样；播完一首就卡死不切歌
- **现在**：正常开播，一次 3 首，播完自动切下一首
- 根因：网易已对 weapi 加密接口全面收紧（登录态+设备指纹也静默拒绝），
  需登录接口全部迁移到**明文通道**（每日推荐 / 我的歌单 / 账号信息同步迁移）

### 🔐 匿名设备身份持久化
- 设备指纹跨重启复用（之前每次启动注册新设备，频繁触发风控）
- 扫码登录 8821 风控出现概率大幅下降

### 🧭 导航栏响应式修复
- 修复 768–900px 窗口宽度下**导航彻底消失**的断点盲区
- 汉堡菜单按钮与桌面导航无缝衔接，任何窗口宽度都有可用导航
- 设置齿轮任何宽度常驻；移动菜单补齐「设置」入口

## 🛡️ 稳定性加固（Web 同步生效）

- **断网处理**：断网拦截切歌、导航栏显示离线横幅、错误提示区分「网络异常」与「服务异常」
- **iOS Safari**：首次触摸解锁音频，修复自动播放无声
- **播放停滞保护**：缓冲卡死 5 秒自动跳下一首（队列耗尽则停下提示）
- **版权/VIP 细分提示**：明确告知「VIP 专属」或「版权下架」，不再笼统报错
- **倍速兼容**：Web Audio 分析链下高倍速自动回落，防破音
- **拖拽优化**：音量/进度条 rAF 帧对齐，拖拽不再卡顿
- **登录指引**：Cookie 获取 5 步图文指引；8821 风控明确引导切换通道

## 🐛 修复
- 退出应用后 **node 后台进程驻留**（Job Object + 显式 kill 双保险，退出即彻底回收）
- 单曲队列播完不切歌（历史死循环漏洞）
- 搜索页「清空历史」在桌面端不生效
- 断网时误报「服务异常(502)」（现正确提示网络异常）

## 📝 说明
- 仅供学习研究，不缓存、不持久化任何版权内容
- 安装包含 Next.js 服务端（网易云代理 API），**完全离线可用**
- 已登录用户升级后首次启动会复用设备指纹，扫码/接口风控概率显著降低
