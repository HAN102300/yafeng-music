# 🎵 雅枫音乐 v0.1.5

> **⬇️ 直接下载下方 `YaFengMusic_0.1.5_x64-setup.exe` 安装**（约 37 MB，含完整离线能力）。
> 已安装 v0.1.0–v0.1.4 的用户：启动约 12 秒后自动提示更新；或在 **设置 → 关于 → 检查更新** 手动检查。

## ✨ 本次更新了什么

### 🎛️ 可视化页控制舱全面升级（核心）
可视化沉浸页的底部控制舱功能与主播放条**全面对齐**，全部按钮收纳于一行：
- **播放队列**：右侧滑出抽屉——切歌 / 移除单曲 / 清空队列，带队列数角标
- **音量调节**：悬停喇叭展开滑条，拖动调节 + 点击静音
- 主控与功能区用分隔线分组：`循环 / 上一首 / 播放 / 下一首 / 喜欢 ┃ 队列 / 音量`
- 无歌状态下打开可视化页，点播放自动开播热歌榜

### 📐 控制舱自适应缩放
- 整舱尺寸随**视口高度**弹性变化：播放主键 / 图标 / 间距 / 进度条粗细全部
  clamp 缩放——窗口拉大舱体饱满、压矮自动紧凑，与圆环/歌词的缩放联动，
  彻底告别一成不变的呆板布局

### ⚡ 可视化质量档（新增设置项）
**设置 → 外观 → 可视化质量**：
- **自动**（默认）：内置帧率探针，连续 5 秒低于 30fps 自动降级（切后台暂停统计）
- **高**：强制完整特效
- **省电**：全场景替换为静态氛围渐变——所有场景（含流光频谱/环形音浪等
  Canvas 2D 场景）切换立现，且后台不再跑动画

### 📜 长列表懒加载
曲目列表（歌单 / 歌手 / 榜单 / 搜索 / 喜欢 / 历史）与播放队列抽屉改为
**分片懒加载**：每批渲染 50 首，滚动接近底部自动追加——几百首的大歌单
滚动如丝般顺滑，首屏渲染更快。

### 🧹 缓存与内存卫生
- 榜单 / 歌单目录 / 热门类接口加 5 分钟内存缓存（LRU 上限 60），页面切换不再重复请求
- 播放地址缓存加 LRU 上限，长时间挂机不再无限增长
- 事件监听全面审计：无泄漏

## 🐛 修复
- 队列抽屉 / 歌词浮层在部分容器内定位偏移（Portal 挂载 body，fixed 定位
  不再被 transform 劫持）
- 可视化页控制舱按钮布局拥挤（合并单行 + 舱体加宽）
- 无歌时可视化页播放按钮无响应
